# `tab_bar_vertical = true`

When set to `true` (the default), the tab bar is rendered vertically
on the left or right side of the window instead of horizontally at
the top or bottom.

When set to `false`, the tab bar is rendered horizontally.

See also:
* [tab_bar_vertical_width](tab_bar_vertical_width.md) to set the width
* [tab_bar_vertical_position](tab_bar_vertical_position.md) to set the side
* [Tab Bar Extra Info](tab_bar_extra_info.md) to configure the info panel
