01 / 项目概述

什么是 TeamShell？

一个基于 Wezterm 终端的多 Agent 协作系统，每个 AI Agent 占用一个终端标签页作为「工位」，通过 TeamShell 协议实现自主协作。

🖥️

终端即工作台

Agent 像人类一样在终端里工作——每个 Agent 占用一个 Wezterm 标签页作为工位，可以查看屏幕、输入命令、操作终端。

🔗

类 MCP 能力

类似 Chrome DevTools MCP，但面向终端——AI 可以操控终端标签页，执行命令、读取输出、模拟人类操作。

👥

多 Agent 自组织

Agent 可以招募新 Agent、委托任务、监管进度、互相帮助。团队可以自组织、自协调、自决策。

📜

TeamShell 协议

一套让 AI Agent 理解自己是团队成员的协议——有工号、有名字、有自主行动能力、有协作规范。

👀

屏幕共享

Agent 可以随时查看队友的终端屏幕，了解队友的工作状态，就像坐在旁边一起工作。

⌨️

远程打字

Agent 可以在队友的终端里输入文字、发送命令，实现真正的协作操作。

🤖

任意 Agent

不绑定特定模型——支持 Claude、Codex 等任意 Agent，灵活选择最适合的工具。

🐚

多 Shell 兼容

支持 pwsh、cmd、zsh、bash、fish 等任意 shell，跨平台无死角，哪里都能用。

💾

会话自动恢复

团队会话自动存储，下次打开时自动恢复所有工位状态，协作不中断。

💰

智能成本优化

主 Agent 只负责思考和监管，具体执行由低成本 Agent 完成，节省 token 的同时不失智能。

⚖️

能力成本平衡

根据任务难度自动调配不同能力/成本的 Agent——简单任务用低成本模型，复杂任务用高性能模型。

03 / 核心功能

命令行接口

简洁而强大的 tsh 命令，让 Agent 协作变得直观可控。

tsh list

列出团队成员

显示所有在职工位，包括工号、名字、当前状态。团队成员可以看到谁在、谁忙、谁空闲。

tsh view <id>

查看队友屏幕

获取指定工位终端的最后 N 行输出，纯只读操作，队友完全感知不到你在观察他。

tsh type <id> "消息"

在队友终端打字

向指定工位的终端输入文字并回车。可以发送文字消息给 Agent 队友，或向程序工位输入命令。

tsh open "名字" -- 命令

招募新 Agent

启动一个新的工位，运行指定的 Agent（Claude、Codex 等）。新 Agent 会自动加载 TeamShell 协议，加入团队。

tsh close <id>

让成员离开

关闭指定工位，终止上面运行的所有程序。未完成的工作会丢失，关闭前会检查是否有重要状态需要交接。

04 / 使用场景

想象一下

当多个 AI Agent 组成团队一起工作时，会发生什么？

01

复杂任务分解

老板把一个大任务交给主 Agent，主 Agent 分析后招募多个专家 Agent 并行处理，各自完成子任务后汇报结果。

并行处理 任务分解 结果汇总
02

代码 Review

开发 Agent 写完代码后，Review Agent 来审查代码，发现问题直接在开发 Agent 的终端里标注、讨论、优化。

质量把控 协作审核 实时讨论
03

协作 Debug

一个 Agent 在调试问题时卡住了，其他 Agent 通过 view 看到他的屏幕，主动 type 帮忙分析、提供思路。

问题求助 主动协助 知识共享
04

模拟团队工作流

不同角色的 Agent——产品 / 开发 / 测试——各自在工位上工作，通过 tsh 命令协调、交接、审批，像真实团队一样运作。

角色扮演 工作流模拟 端到端
05

人类监管

人类老板坐在「主控室」，可以随时 tsh view 查看任何 Agent 的工作状态，在必要时 tsh type 介入指导。

人工监管 随时介入 安全可控
06

运维自动化

多个运维 Agent 分工监控不同服务器，一个 Agent 发现异常自动招募专家 Agent 来处理，自动化工运维。

多机协作 自动响应 故障恢复
05 / 价值与意义

为什么重要？

TeamShell 首次实现了 AI Agent 的「团队工作模式」

3-5x

效率提升

把串行的单 Agent 任务变成并行的多 Agent 协作，复杂任务完成时间大幅缩短。更重要的是，主 Agent 只负责思考和监管，具体执行由低成本 Agent 完成，节省 token 的同时不失智能。综合效率可提升 3-5 倍。

∞

社会价值

为未来 AI 团队协作提供基础设施，可应用于软件开发自动化、运维自动化、研究助理等领域，开启 AI 协作新时代。系统不绑定任何特定模型或平台，支持任意 Agent 和任意 shell，具有良好的通用性和可扩展性。
