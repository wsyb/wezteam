TeamShell CLI 帮助

Usage

tsh.exe <COMMAND>

Commands

list                 列出所有工位
view <工号> [行数]    查看工位屏幕
type <工号> "文本"   发送消息（自动回车）
  --no-enter          不自动回车
  --key "\x03"        发送Ctrl+C等
name <工号> "新名"   重命名工位
open "名字" -- <类型> 招聘成员(claude/codex/traecli)
close <工号>         关闭工位
init <协议文件>       初始化协议
help                 显示帮助

Options

-h, --help     显示帮助  -V, --version  版本
