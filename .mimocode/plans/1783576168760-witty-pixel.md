# 端口文件路径 CWD 依赖修复

## 问题

`platform_default_port_path_for_pid()` 优先用 `current_dir()` 拼接路径。服务端和客户端 CWD 不同时，客户端找不到端口文件。

```
wezterm-gui CWD=/mnt/code/work/wezteam/ → 写入 .teamshell-port-77920
tsh CWD=/home/fy/ → 查 CWD/.teamshell-port-* → 没有 → 扫描 /tmp/ → 也没有 → 报错
```

## 修复

Unix 上直接用 `/tmp/.teamshell-port-{pid}`，不依赖 CWD。`/tmp` 是所有 Unix 系统的共享可写目录。

### 文件：`teamshell-ipc/src/lib.rs`

删除 `platform_default_port_path()` 和 `platform_default_port_path_for_pid()` 中的 CWD 逻辑，直接返回 `/tmp/` 路径：

```rust
#[cfg(unix)]
fn platform_default_port_path() -> PathBuf {
    PathBuf::from("/tmp/.teamshell-port")
}

#[cfg(unix)]
fn platform_default_port_path_for_pid(pid: u32) -> PathBuf {
    PathBuf::from(format!("/tmp/.teamshell-port-{}", pid))
}
```

Windows 逻辑不变（已使用 `LOCALAPPDATA`，不依赖 CWD）。

### 验证

1. 启动 wezterm-gui，确认端口文件写入 `/tmp/.teamshell-port-{pid}`
2. 从任意目录执行 `tsh status`，确认能找到端口文件并连接成功
3. 杀掉 wezterm-gui，确认 `tsh status` 检测到 PID 不存活并报错
